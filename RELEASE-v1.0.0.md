# NeoLift v1.0.0 — Initial Mobile Release

Primeira versão pública do NeoLift, um tracker de treino offline-first feito com Expo e React Native.

## Destaques
- catálogo aberto de exercícios com busca e filtros;
- treino livre persistente com séries, peso e repetições;
- gráficos por exercício e por região muscular;
- painel de evolução para o corpo completo;
- temas claro/escuro/sistema;
- dados de treino armazenados localmente em SQLite;
- verificação de novas versões pelas GitHub Releases;
- fluxo de atualização Android por APK anexado à release;
- interface compartilhada e consistente em Android e iOS.

## Dados
O catálogo usa dados do free-exercise-db (Unlicense/public domain). O histórico pessoal do usuário não precisa de backend e fica no dispositivo.
