# NeoLift v1.2.0 — Visual Identity

Esta versão apresenta uma identidade visual própria para o NeoLift e consolida a atualização técnica para o Expo SDK 57.

## Destaques

- Novo símbolo do NeoLift: um monograma **N** ascendente que comunica força, progresso e evolução.
- Novo ícone principal com fundo grafite e paleta cyan/violeta.
- Adaptive icon Android redesenhado com safe zone apropriada.
- Novo splash e marca transparente em alta resolução.
- Wordmarks para aplicações sobre fundos claros e escuros.

## Plataforma e compatibilidade

- Expo atualizado para `~57.0.12`.
- Expo Router atualizado para `~57.0.12`.
- React Native atualizado para `0.86.2`.
- Dependências nativas deduplicadas e alinhadas ao SDK 57.
- TypeScript atualizado para a linha 6.0.
- `android.versionCode` e `ios.buildNumber` incrementados para `3`.

## Qualidade

- `expo-doctor`: 20/20 verificações aprovadas.
- Typecheck aprovado.
- Verificação de consistência da versão aprovada.

## Android

O APK desta release é distribuído como `NeoLift-v1.2.0.apk`. Para que a atualização sobre uma versão anterior funcione, o APK deve usar a mesma chave de assinatura.
